const themeToggle = document.getElementById('themeToggle');
themeToggle.addEventListener('click', () => {
    const cur = document.documentElement.getAttribute('data-theme');
    const target = cur === 'dark' ? 'light' : 'dark';
    document.documentElement.setAttribute('data-theme', target);
    localStorage.setItem('theme', target);
});

Chạy Toàn Bộ Website Local Bằng Python

Chỉ cần 1 lệnh hoặc 1 lần nhấp đúp file run.py, hệ thống tự tạo web server cục bộ và tự mở trình duyệt web lên màn hình ngay lập tức.

1
Mở thư mục dự án: Điều hướng vào thư mục bui-ngoc-ha-profile
2
Chạy lệnh Python:
python3 run.py
3
Tự động mở: Trang web sẽ tự động hiển thị tại http://localhost:8000
