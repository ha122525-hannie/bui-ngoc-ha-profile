## 💻 Danh Sách Các Ngôn Ngữ Web & Công Nghệ Sử Dụng

1. **HTML5:**
   - Xây dựng cấu trúc trang theo chuẩn ngữ nghĩa Semantic HTML (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
   - Tối ưu hóa SEO với đầy đủ thẻ Meta Title, Meta Description, Open Graph.
   
2. **CSS3 (Vanilla CSS):**
   - Thiết kế giao diện theo phong cách **Glassmorphism** và chuyển màu Gradient hiện đại.
   - Hỗ trợ 2 chế độ màu **Dark Mode / Light Mode** linh hoạt qua CSS Variables.
   - Bố cục Responsive 100% bằng CSS Flexbox và CSS Grid, tối ưu cho cả điện thoại, máy tính bảng và desktop.
   - Hiệu ứng chuyển động (Micro-animations) mượt mà cho các nút bấm, thẻ bài viết.

3. **JavaScript (ES6+):**
   - Hiệu ứng gõ chữ tự động (Typewriter Effect) ở phần Hero.
   - Xử lý chuyển đổi giao diện Sáng / Tối và lưu trạng thái vào `localStorage`.
   - Tính năng sao chép dòng lệnh và code snippet một chạm với thông báo Toast trực quan.
   - Tương tác mở / đóng menu di động và theo dõi vị trí cuộn trang (Scroll Spy).

4. **Python 3 (Local Server & Auto Launcher):**
   - Sử dụng thư viện chuẩn của Python (`http.server`, `socketserver`, `webbrowser`, `threading`).
   - Không cần cài thêm thư viện ngoài (zero-dependencies), tự động mở trình duyệt mặc định chỉ với 1 thao tác.

5. **Công cụ phát triển:**
   - **Visual Studio Code:** IDE soạn thảo mã nguồn.
   - **Git & GitHub:** Hệ thống quản lý phiên bản mã nguồn (Version Control System).

## 🚀 Hướng Dẫn Chạy Website (Chỉ 1 Click)

### Cách 1: Chạy bằng file Python (Khuyên dùng)
Mở Terminal hoặc Command Prompt tại thư mục dự án và gõ:
```bash
python3 run.py
# hoặc trên Windows:
python run.py
```
> **Đặc điểm:** Script sẽ tự động bật web server tại cổng `http://localhost:8000` và **tự động mở trình duyệt web** ngay lập tức mà không cần gõ URL thủ công!

### Cách 2: Nhấp đúp chuột trực tiếp
- **Trên Windows:** Nhấp đúp vào file `run.bat`.
- **Trên macOS / Linux:** Nhấp đúp hoặc chạy `./run.sh`.

### Cách 3: Mở trực tiếp
Nhấp đúp vào file `index.html` để mở xem trên bất kỳ trình duyệt nào (Chrome, Edge, Safari, Firefox).
