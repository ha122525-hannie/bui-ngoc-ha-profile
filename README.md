## 💻 Danh Sách Các Ngôn Ngữ Web & Công Nghệ Sử Dụng

1. **HTML5:** Cấu trúc trang chuẩn ngữ nghĩa Semantic HTML, tối ưu hiển thị.

## 🚀 Hướng Dẫn Chạy Website (Chỉ 1 Click)

### Cách 1: Chạy bằng file Python (Khuyên dùng)
Mở Terminal hoặc Command Prompt tại thư mục dự án và gõ:
```bash
python3 run.py
# hoặc trên Windows:
python run.py
```
> **Đặc điểm:** Script sẽ tự động bật web server tại cổng `http://localhost:8000` và **tự động mở trình duyệt web** ngay lập tức mà không cần gõ URL thủ công!

### Cách 2: Nhấp đúp chuột trực tiếp
- **Trên Windows:** Nhấp đúp vào file `run.bat`.
- **Trên macOS / Linux:** Nhấp đúp hoặc chạy `./run.sh`.

### Cách 3: Mở trực tiếp
Nhấp đúp vào file `index.html` để mở xem trên bất kỳ trình duyệt nào (Chrome, Edge, Safari, Firefox).
